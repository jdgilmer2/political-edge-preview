## GitHub Pages Setup

1. Create a public GitHub repository.
2. Upload `index.html` and `political-edge-logo.svg`.
3. Open the repository settings.
4. Go to Pages.
5. Set the source to deploy from the `main` branch and root folder.
6. Save and wait for GitHub to generate the public URL.
